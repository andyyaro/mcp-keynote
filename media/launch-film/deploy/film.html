mcp-keynote builds the whole deck from one spec, in one call.

Claude writes one spec: slides, tables, charts, notes and transitions. The server checks all of it before anything is created. A typo or an invented key comes back named, with what to use instead.

Your text reaches AppleScript as arguments, never pasted into the script, so a title full of quotes can't break it, or take it over.

Then Keynote builds native tables with live formulas, 17 chart types and styled connectors, and exports to PDF, PowerPoint, a movie or HTML. describe_deck reads an open deck back into the same spec, ready to diff in git.

757 unit tests pass. On a real Keynote, 289 live checks ran: none failed.

It rebuilds ByAxe's keynote-mcp, a fork of easychen's original.

mcp-keynote. Keynote decks, built from one declarative spec.

MCP Keynote began as keynote-mcp by easychen (2025). ByAxe's fork translated it into English, packaged it for PyPI and added the keynote-presentation skill and the build-animation tools. This repository is Andy Yaro's rebuild on top of ByAxe's fork, 49 commits on.

The validation reply and the AppleScript lines in the film are real outputs, captured from the code with osascript mocked. The slide thumbnails are redrawn from specs in the repository, which holds no slide screenshots; Keynote was not driven for the film. The 289 live checks are quoted from the 4.1.0 changelog.
